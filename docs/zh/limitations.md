# 局限 {#limitations}

!!! note "固定声明"
    使用 NeuroGrid 进行的预检。不构成国家药品监督管理局（NMPA）法规意义上的符合性评价。

## 结果的含义 {#meaning}

NeuroGrid 是一个预检工具。结果只说明数据集是否通过已加载规则包的各项检查，不说明其他内容；符合性评价由检验机构和
国家药品监督管理局（NMPA）进行。NeuroGrid 只评价数据集，从不评价任何个人；它不是医疗器械，也不提供法律意见。

## 规则包与阈值 {#thresholds}

- **gxdsl008** 的五个起始值为转引：无法获取 T/GXDSL 008-2025 的标准原文，所有条款均为“未知”，也不计算覆盖率。
  其所有规则都是警告。
- **已校准的阈值**（M06、M07、M09）是五个公开 OpenNeuro 数据集（22 条记录、1050 个通道）上的第 95 百分位数。它们
  可能不适用于其他设备、导联或人群；请检验，并附理由覆盖。
- 0.1 版不包含 YY/T 2029-2026 的任何内容。yyt2029 规则包将在研读标准文本后提供。

## 方法 {#methods}

- M06 和 M09 在抽样上运行（默认 10 × 60 秒）；抽样之外的局部干扰不会被它们发现。M07 和 M08 始终使用整条记录。
  `[sampling] mode = "full"` 使用整条记录。
- M09：对干净数据，autoreject 常常拒绝 0 %，ICLabel 比例则取决于成分数量；两者都难以在不同设备之间比较。
- M12 只能发现完全相同的重复，不能发现部分重复。
- 数据嵌入 `.set` 文件中的 EEGLAB 数据集无法分块读取；其内存占用约等于文件大小。
- BIDS 验证器 3.0.2 按其自带的模式（BIDS 1.11.1）验证，而当前规范为 BIDS 1.11.2。高于 8.4.0 的 HED 模式无法离线
  获得，会作为单独的检查结果列出。
- `[convert] pattern` 中相邻且相互重叠的重复无法被识别，可能使运行非常缓慢（Ctrl+C 可结束运行）。

## 平台 {#platforms}

Windows 11 已在本地验证。Windows 10 和 Linux（Debian 12、Ubuntu 22.04 及以上）在首次 CI 运行前未验证；其他 Linux
发行版和 ARM64 不受支持（[安装](installation.md#platforms)）。

## 不属于 0.1 版的内容 {#not-in-v01}

- `diff`（比较两次结果）、NeuroVault（知情同意、角色、访问日志、M14）和证明材料汇编将在后续版本中提供。
- GB/T 47127 作为输入和输出格式将随 0.2 版提供。
- 本文档随离线安装包和构建产物发布；其网站将在正式发布时决定。
